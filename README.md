# 🍁 PR Journey: The Endless Runner

> **Disclaimer:** This is a fan-made game for entertainment purposes only. It is not affiliated with, endorsed by, or connected to Immigration, Refugees and Citizenship Canada (IRCC) or the Government of Canada. CRS scores, processing times, and immigration rules depicted are fictional and used purely for gameplay mechanics.

A **2D side-scrolling endless runner** built with **Godot 4.3 (GDScript 2.0)** themed around the Canadian Permanent Residency journey. Input your real (or imaginary) CRS/CEC score and run through the IRCC obstacle course — dodging Refusal Letters, leaping over Document Requests, and collecting PNP Nominations — until you reach the **PR Card** at the finish line. 🏆

## 🎮 Gameplay

### Flow
```
Start Screen (enter CRS/CEC)
       ↓
   Game Scene  ──► Win Screen  🏆  (reached PR distance goal)
       │
       └────────► Game Over Screen  ❌  (ran out of lives)
```

### Controls

| Action | Keyboard | On-Screen Button | Touch |
|--------|----------|-----------------|-------|
| Jump   | `Space` / `↑` | **JUMP** button | Tap screen |
| Duck   | `↓` | **DUCK** button | Swipe down |

### Obstacles (dodge these!)

| Emoji | Name | Type | How to avoid |
|-------|------|------|-------------|
| 📄 | Additional Document Request (ADR) | Ground | Jump over |
| ⏳ | Processing Delay | Wide ground | Jump over |
| 🚫 | Refusal Letter | Flying | Duck under |
| 🩺 | Medicals Re-do | Ground | Jump over |
| 👆 | Biometrics Appointment | Flying | Duck under |

Each hit costs 1 life and grants 0.8 s of invincibility.

### Power-ups (collect these!)

| Emoji | Name | Effect |
|-------|------|--------|
| 🍁 | NOC Coin | +50 points |
| 📈 | CRS Boost | 3 s speed boost + invincibility |
| 🎓 | PNP Nomination | +600 points _(rare — 10% chance)_ |
| 💼 | LMIA Job Offer | Shield — absorbs 1 hit |

### Milestones

| Progress | Milestone |
|----------|-----------|
| 0 % | Express Entry Pool 🌊 |
| 25 % | ITA Received! 🎉 |
| 50 % | Documents Submitted 📁 |
| 75 % | Background Check 🔍 |
| 90 % | Medicals Cleared ✅ |
| 100 % | **PR CARD! 🏆** |

## 📊 How CRS / CEC Affects Gameplay

| CRS Range | Lives | Speed (px/s) | Obstacle interval | Distance goal |
|-----------|-------|-------------|------------------|---------------|
| 0 – 199 | 1 | 300 | 2.0 s | 8 000 px |
| 200 – 399 | 2 | 380–460 | ~1.5 s | 6 000–7 200 px |
| 400 – 469 | 2–3 | 460–488 | ~1.2 s | 4 400–5 600 px |
| 470+ | 3+ | 488+ | ≤ 1.1 s + **double-jump** unlocked | ≤ 4 200 px |
| 1 000+ | 5–6 | 700 | 0.7 s | 4 000 px |

**Formulas (from `GameState.gd`):**
```
lives            = clamp(floor(crs / 200), 1, 6)          [+1 if CEC > 0]
base_speed       = 300 + (crs × 0.4)   pixels/sec
obstacle_density = clamp(1.5 - (crs / 1000), 0.4, 1.4)   (lower = fewer)
pr_distance_goal = 8000 - clamp(crs × 4, 0, 5000)         pixels
double_jump      = crs >= 470
cec_bonus        = +1 life + starting shield  (if CEC > 0)
```

## 🛠 Opening the Project in Godot 4.3

1. **Download Godot 4.3** from [godotengine.org](https://godotengine.org/download/) (standard or .NET — either works).
2. **Clone this repository:**
   ```bash
   git clone https://github.com/bhavyat81/PRgame.git
   cd PRgame
   ```
3. Open Godot → **Import** → browse to the cloned folder → select `project.godot` → **Import & Edit**.
4. Press **F5** (or the ▶ Play button) to run the game on desktop.

> The project uses the `GL Compatibility` renderer (mobile-compatible) so it will run on any platform without extra setup.

## 📱 Exporting to Android

### Prerequisites
- Godot 4.3 with **Android export templates** installed  
  _(Editor → Export Templates → Download)_
- [Android Studio](https://developer.android.com/studio) with:
  - Android SDK (API 33+)
  - JDK 17 (bundled with Android Studio)
- A debug keystore (auto-generated by Android Studio, or run:  
  ```bash
  keytool -genkey -v -keystore debug.keystore -alias androiddebugkey \
    -keyalg RSA -keysize 2048 -validity 10000 -storepass android -keypass android
  ```

### Steps
1. **Editor → Editor Settings → Export → Android** — set:
   - `Android SDK Path` → your SDK folder (e.g. `~/Library/Android/sdk`)
   - `Java SDK Path` → your JDK folder
2. **Project → Export** → select the **Android** preset.
3. Fill in `Keystore → Debug` path and credentials (password `android`, user `androiddebugkey`).
4. Click **Export Project** → choose **Debug APK**.
5. Install on device:
   ```bash
   adb install -r path/to/PRJourney.apk
   ```

For a **Release APK** (Google Play), generate a release keystore and sign the build accordingly.

## 🍎 Exporting to iOS

> Requires a **Mac with Xcode 15+** and an Apple Developer account.

### Prerequisites
- Godot 4.3 with **iOS export templates** installed
- Xcode installed from the Mac App Store
- Apple Developer Program membership (for device deployment / App Store)

### Steps
1. **Project → Export** → select the **iOS** preset.
2. Fill in:
   - `Bundle Identifier` → e.g. `com.yourname.prjourney`
   - `App Store Team ID` → your 10-character team ID from developer.apple.com
3. Click **Export Project** → this generates an **Xcode project** folder.
4. Open the `.xcodeproj` in Xcode.
5. Select your **Team** under _Signing & Capabilities_.
6. Connect your iPhone/iPad → press **▶ Run** in Xcode.

For App Store submission, archive the project in Xcode and upload via **Xcode Organizer**.

## 📁 Project Structure

```
PRgame/
├── project.godot          # Godot 4.3 project config (viewport, input, autoload)
├── export_presets.cfg     # Android + iOS export preset stubs
├── icon.svg               # Maple leaf app icon
├── default_env.tres       # Default environment resource
├── .gitignore
├── README.md
├── scenes/
│   ├── Main.tscn          # Entry point — routes to StartScreen
│   ├── StartScreen.tscn   # CRS / CEC input form
│   ├── Game.tscn          # Endless runner gameplay
│   ├── WinScreen.tscn     # "You got your PR Card!" celebration
│   ├── GameOverScreen.tscn# "Application Refused" screen
│   ├── Player.tscn        # Player character (CharacterBody2D)
│   ├── Obstacle.tscn      # Generic obstacle (Area2D)
│   ├── Powerup.tscn       # Generic powerup (Area2D)
│   └── HUD.tscn           # Score, distance bar, lives, on-screen buttons
└── scripts/
    ├── GameState.gd        # Autoload singleton — CRS/CEC difficulty mapping
    ├── Main.gd
    ├── StartScreen.gd
    ├── Game.gd             # Main game loop, spawning, scrolling
    ├── WinScreen.gd
    ├── GameOverScreen.gd
    ├── Player.gd           # Jump / duck physics + touch gestures
    ├── Obstacle.gd         # Type enum, visuals, collision
    ├── Powerup.gd          # Type enum, bobbing animation, effects
    ├── HUD.gd              # Procedural HUD + on-screen buttons
    └── ParallaxBackground.gd  # Stub for future parallax layers
```

All visual assets are **procedurally generated** using `ColorRect`, `Polygon2D`, and `Label` nodes — no binary image files are required.
